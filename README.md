# 🏫 Math School – Python Project

## 📖 About the Project

Math School is a beginner-friendly, menu-driven Python application developed to help primary school children learn and practise basic mathematical concepts.

The main objective of this project is to make mathematics learning simple, interactive, and enjoyable through Python programming.

Students can select different mathematical topics, enter numbers, and get answers through the application.

## 🎯 Project Objectives

- Make mathematics easy and interesting for children.
- Help students understand basic mathematical concepts.
- Provide an interactive learning experience.
- Practise mathematical problems through Python functions.
- Develop logical thinking and problem-solving skills.

## 🚀 Features

### 1. Even and Odd Numbers
- Check whether a number is even or odd.
- Generate a range of even and odd numbers.

### 2. Prime Numbers
- Check whether a number is prime or not.
- Generate prime numbers within a given range.
- Find the Nth prime number.
- Find prime factors of a number.

### 3. Mathematical Operations
- Generate multiplication tables.
- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division operations.

### 4. Number Calculations
- Calculate factorials.
- Find divisors of a number.
- Calculate the sum of divisors.
- Calculate the sum of natural numbers.
- Calculate the sum of digits.

### 5. Special Numbers
- Check strong numbers.
- Generate strong numbers within a range.
- Check Armstrong numbers.
- Generate Armstrong numbers within a range.

## 🛠️ Technologies Used

- Programming Language: Python
- Concepts: Functions, Loops, Nested Loops, Conditional Statements, User Input, and Menu-Driven Programming.

## 💻 How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Open Command Prompt or Terminal.
5. Execute the following command:

```bash
python primaryschoolproblems.py
```
